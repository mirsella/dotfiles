description: Review the current work and recommend concrete follow-ups and next steps. Use when the user asks for recommendations or what to do next.
---

Recommend useful remaining work, follow-ups and possible next steps. Separate
necessary work from optional ideas, giving each a concrete action and expected
benefit. Don't pad recommendations with routine tests, manual checks, benchmarks
or deployments unless they address a specific uncovered risk or uncertainty.
Reuse valid verification and don't present fixed issues as outstanding. If the
requested scope is complete, say so; useful optional directions are still welcome.
Recommend changes, don't implement them unless asked.
